## What Is Shadcn UI?

Shadcn UI is not a component library in the traditional sense. Instead of installing a package and importing components, you copy the source code directly into your project. This gives you complete ownership and flexibility.

Built on top of **Radix UI** primitives and styled with **Tailwind CSS**, Shadcn UI components are accessible, customizable, and production-ready from day one.

## Getting Started

```bash
npx shadcn@latest init
```

After initialization, add components one by one as you need them:

```bash
npx shadcn@latest add button
npx shadcn@latest add dialog
```

Each component lands directly in your `components/ui` folder—fully editable.

## Key Benefits

### Accessibility by Default

Every Shadcn UI component is built on Radix UI, which handles keyboard navigation, ARIA attributes, and focus management automatically.

### No Dependency Lock-In

Because you own the code, you're never blocked by an upstream library decision. Need a custom animation? Change it. Need a different API? Refactor it.

### Consistent Theming

Shadcn UI uses CSS variables for theming. Swap your entire color palette with a few lines in your global CSS file.

## Conclusion

Shadcn UI represents a new philosophy for component libraries: give developers the building blocks, not a black box. If you haven't tried it yet, your next project is the perfect opportunity.
