Es gab eine Zeit, als das Internet ein Ort war, den man besuchte, kein Ort, an dem man lebte. Man öffnete einen Browser, navigierte zu einer Seite, las etwas und schloss ihn wieder. Das Erlebnis hatte Grenzen. Es hatte Enden.

## Die Beschleunigung

Irgendwo unterwegs wurde das Web ambient. Feeds ersetzten Seiten. Benachrichtigungen ersetzten Besuche. Das Erlebnis wurde unendlich – und indem es unendlich wurde, wurde es erschöpfend.

Unendliches Scrollen sollte ein Feature sein. Es beseitigte die Reibung des Klickens auf „nächste Seite". Aber Reibung, wie sich herausstellt, hatte wichtige Arbeit getan. Sie gab uns einen Moment zu entscheiden: *Will ich weitermachen?*

## Wie das langsame Web aussieht

Das langsame Web dreht sich nicht um Geschwindigkeit – es dreht sich um Intentionalität. Es ist ein Newsletter, auf den Sie sich freuen. Ein Blog, den Sie bookmarken und zu dem Sie zurückkehren. Ein Podcast, den Sie vollständig hören, nicht auf 2-facher Geschwindigkeit.

Langsame Web-Erlebnisse teilen bestimmte Qualitäten:

1. **Sie haben einen Anfang, eine Mitte und ein Ende.** Sie beenden sie.
2. **Sie belohnen Aufmerksamkeit.** Je mehr Sie geben, desto mehr bekommen Sie.
3. **Sie respektieren Ihre Zeit**, indem sie nicht versuchen, sie ganz zu stehlen.

## Für das langsame Web bauen

Wenn Sie für das langsame Web bauen, helfen einige Prinzipien:

- Tiefe gegenüber Breite bevorzugen. Ein ausgezeichneter Artikel schlägt zehn mittelmäßige.
- Inhalte auffindbar machen, nicht nur teilbar.
- Für Rückbesuche entwerfen, nicht nur für erste Eindrücke.
- Für Menschen schreiben, nicht für Algorithmen.

## Der Fall für Letter Club

Ein Letter Club – eine Gruppe von Menschen, die Langform-Texte austauschen – ist das soziale langsame Web. Es ist E-Mail in ihrer durchdachtesten Form. Keine Engagement-Metriken, keine algorithmische Verstärkung. Nur Worte, sorgfältig geschrieben, für Menschen, die sie zu empfangen gewählt haben.

Das langsame Web wird das schnelle Web nicht ersetzen. Aber es bietet etwas, das das schnelle Web nicht kann: Tiefe, Ruhe und die stille Befriedigung, etwas wirklich zu beenden.
